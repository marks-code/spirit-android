# Spirit for Android

Watch YouTube without ads, save videos and music to your phone, and listen with the screen off. Everything runs on your phone; there's no account or server to set up.

## Install

1. On your Android phone, open the [latest release](../../releases/latest) and tap **Spirit-….apk** to download it.
2. Open the downloaded file. If Android asks, allow your browser to **install unknown apps**, then tap **Install**.
3. Open Spirit. The first launch takes about 30 seconds while it sets itself up.

Needs Android 7 or newer on a 64-bit phone (any phone from the last several years).

## Get updates automatically

Install [Obtainium](https://github.com/ImranR98/Obtainium), tap **Add app**, and paste this page's address. Obtainium will let you know when there's a new version and install it for you.

You can also download the new APK from Releases and install it over the old one. Your downloads and settings stay.
